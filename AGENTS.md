# glassnode-terminal: agent instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) first: setup, project layout, conventions, the version
bump and the release flow all live there. Before opening a PR, run the checks in its "Run the
local checks" step.

## Don't

- Edit `src/lib/x402-catalog.ts` by hand: it is generated by `pnpm run gen:x402-metrics`
  (`scripts/generate-x402-metrics.mjs`).
- Run `pnpm run gen:x402-metrics` or the app against the live API unless asked: it needs a real
  `GLASSNODE_API_KEY`, and in x402 mode (`X402_PRIVATE_KEY`) every call, metadata included,
  spends USDC from a real wallet. Tests and the CLI smoke test need no credentials.
- Change `scripts/release-*.{sh,mjs}` here alone: they are shared with
  [glassnode-api-ts-client](https://github.com/glassnode/glassnode-api-ts-client) and tested in
  `test/release-scripts.spec.ts`. Say in the PR that the other repo needs the same change.
- Move a GitHub Action to a tag such as `@v7`: every action is pinned by full commit SHA (see
  CONTRIBUTING.md "CI and workflows").
